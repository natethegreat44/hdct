# hdct
Handy Dandy Command Line Tools

This project is intended to be a handy, cross-platform suite of simple tools that speed up the processes involved in development and data engineering.

So far, we have:
- epochtime - converts an epoch time integer to a human readable datetime, in UTC
- fw2delim - convert fixed-width data to delimited data
- nu - adds column and line numbers to a file. Intended to help discover fixed-width data sizes, but useful for other things as well.
- uuidgen - create a UUID (v4) and paste it to the clipboard
